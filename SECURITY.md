# Security

PebbleDose is an early household application intended for a trusted local network. Kiosk access is open by default; adult administration requires a PIN. Do not expose the kiosk directly to the public Internet. Use HTTPS for access from other devices and keep database backups private.

Report suspected vulnerabilities through GitHub's private vulnerability reporting on this repository's Security tab. Include reproduction steps using fictional data. Do not post credentials, household records, or exploitable details in a public issue.

There is no guaranteed response time or long-term support policy yet. Security fixes target the current main branch.
